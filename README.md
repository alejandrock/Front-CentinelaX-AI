# CentinelaX UI Ready

Proyecto React + Vite listo para correr localmente sin errores.

## Requisitos
- Node.js 18 o superior

## Instalación
```bash
npm install
npm run dev
```

## Abrir en navegador
```bash
http://localhost:5173
```

## Qué incluye
- Dashboard
- Análisis de URL
- Incidentes
- Logs Linux
- Correlación
- Usuarios
- Perfil
- Login demo

No usa Tailwind ni shadcn. Es una versión limpia, directa y ejecutable.
